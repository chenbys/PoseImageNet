# PoseImageNet

**PoseImageNet: Pose Estimation for Extensive Classes Based on Rich Structure Prototypes**

This repository contains:

- **Project page (paper website)** — served via GitHub Pages at the repository root.
  Visit: `https://<USERNAME>.github.io/<REPO>/` (enable in Settings → Pages after the first push)
- **`code/`** — dataset toolkit / source code (to be added later)

## Project page

The website is fully static (plain HTML/CSS/JS, inline SVG charts, no build step):

| Path | Role |
|---|---|
| `index.html` | Landing page |
| `style.css` / `app.js` | Styling and rendering |
| `data/site-data.js` | All statistics and chart data (single source of truth) |
| `assets/img/` | Figures and sample overlays |
| `scripts/` | Scripts that regenerate `data/site-data.js` and gallery images |
