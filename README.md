# PoseImageNet

**PoseImageNet: Pose Estimation for Extensive Classes Based on Rich Structure Prototypes**

This repository hosts the project page and annotation release of PoseImageNet.

**Project homepage:** [https://chenbys.github.io/PoseImageNet/](https://chenbys.github.io/PoseImageNet/)

On the homepage you can:

- Download the annotations (`PoseImageNetAnnotations.zip`)
- Browse samples and statistics
- Find BibTeX citations and related resources

## Usage

Annotations are released for **research use only**.  
Images are derived from ImageNet and UniKPT; please comply with their respective licenses.  
If you use PoseImageNet, please cite our papers.

If you need the complete dataset (including source images) or have questions about rebuilding it, feel free to contact [chen.bys@outlook.com](mailto:chen.bys@outlook.com).
